# 👩🏻‍💻‌ NodeJS Projects Collection

Bienvenue dans mon dépôt regroupant l’ensemble de mes projets développés avec **Node.js**.
Ce repository centralise plusieurs applications backend illustrant ma progression, mes expérimentations et ma maîtrise croissante de l’écosystème JavaScript côté serveur.


## 📁 Structure du Repository

Le dépôt contient plusieurs dossiers, chacun correspondant à un projet Node.js distinct :

```
📦 nodejs-projects
 ┣ 📂 project-1/
 ┣ 📂 project-2/
 ┣ 📂 project-3/
 ┣ 📂 ...
 ┗ 📄 README.md
```

Chaque dossier inclut sa propre documentation et son propre code, permettant une exploration indépendante.


## 🛠️ Technologies & Concepts Utilisés

Les projets inclus couvrent un large éventail de thématiques Backend, tels que :

* **Node.js** (runtime JavaScript)
* **Routing, middleware, gestion des erreurs**
* **Fichiers JSON & gestion des données locales**
* **Asynchronisme (promises, async/await)**
* **Serveurs HTTP et websockets**

## ▶️ Comment Exécuter un Projet

Chaque projet contient ses propres instructions, mais en général :

1. **Accéder au projet**

```bash
cd project-name
```

2. **Installer les dépendances**

```bash
npm install
```

3. **Lancer le serveur**

```bash
npm start
```

ou

```bash
node app.js
```
